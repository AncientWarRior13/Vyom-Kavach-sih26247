# Data Sources, Licenses & Attribution

RadarSense uses one simulated dataset (generated by this repo, no license
concerns) and four real-sensor datasets sourced externally for the
sim-to-real validation bridges. This document consolidates source,
license, and citation for each, for research-integrity/attribution purposes.

## Simulated dataset (primary training/eval data)

Generated by `radarsense/simulator.py`, entirely original to this project.
No external license applies.

## Reference paper (companion work, not this project's own claim)

"UAV Classification Using Attentive Binarized CNN for Micro-Doppler
Spectrograms," Paul & Bandyopadhyay, IEEE Access, 2026,
DOI 10.1109/ACCESS.2026.3675490 — published under CC-BY-4.0 (stated
explicitly on the paper itself: "© 2026 The Authors. This work is licensed
under a Creative Commons Attribution 4.0 License"). Cited in
`radarsense/diat_usat_bridge.py` and `radarsense/diat_usat_cnn.py` for
context on the DIAT-µSAT dataset and as a comparison point for the
image-native CNN classifier; this project's own binarized-CNN-inspired
implementation is an independent, scoped-down reimplementation, not a copy
of the paper's code.

## What's included in this repo vs. excluded

Raw external datasets (`external_data/`) and the DIAT-uSAT raw archive
(`DIAT-uSAT_dataset.zip`) are excluded from version control (`.gitignore`) —
only the derived, schema-mapped feature parquets and the trained models are
retained. This avoids redistributing third-party raw data under licenses
this project doesn't control, while keeping the derived results (which are
this project's own transformation/analysis) fully reproducible from the
documented bridge scripts, given access to the original source data.
